# Olivo's Landscaping

A simple, lightweight website built with HTML, CSS, and JavaScript.

## Overview

This project is a small, mostly static website that was built for a local landscaping company.

## Features

- Responsive page layout
- Simple navigation
- Basic JavaScript support
- Easy to deploy

## Technologies

- HTML5
- CSS3
- JavaScript

## Getting Started

### 1. Clone or download the project

```bash
git clone https://github.com/your-username/your-project-name.git
```

### 2. Open the project folder

To open the project in the editor

```bash
cd Olivos_Landscaping
code .
```

### 3. Run the website

Just open `index.html` in a web browser.

For local development, you can also use a development server such as the Visual Studio Code Live Server extension.
